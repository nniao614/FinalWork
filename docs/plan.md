# 技术方案与时间规划

## 1. 题目与核心主张

**暂定题目**：面向票据关键信息抽取的修正收益感知字段级路由方法

**一句话概括**：小模型（LayoutLMv3）先抽取所有字段；一个自己设计并训练的**路由网络**判断每个字段“交给大模型（Qwen2.5-VL）复核后能不能被改对”，只把值得复核的字段送给大模型。

**论文要证明的主张**：在准确率接近“只用大模型”的前提下，把耗时和大模型调用量降到接近“只用小模型”；
并且在相同调用预算下，路由网络挑出的字段被改对的数量明显多于“按置信度挑”和“随机挑”。

> 具体实现细节（数据结构、网络公式、缓存格式、开发顺序）见 `docs/algorithm.md`。

## 2. 方法

### 2.1 通俗理解

| 角色 | 对应模块 | 特点 |
|---|---|---|
| 实习生 | 小模型 LayoutLMv3 | 快、便宜，大部分正确，偶尔出错，自报的把握不太准 |
| 老会计 | 大模型 Qwen2.5-VL-3B（LoRA） | 准但慢，不能每张都看 |
| 审核主管 | **路由网络（本文设计）** | 判断哪个字段交给老会计能被改对 |

### 2.2 整体流程

```
票据图像 + OCR
   │
   ▼
LayoutLMv3 抽取 ──► 每个字段：预测值、词级概率向量、隐藏层向量
   │
   ▼
特征构造 ──► 片段池化 + 全局字段查询池化（门控融合）+ 置信度/熵/概率向量 + 字段类型/位置 + 一致性校验结果
   │
   ▼
路由网络 ──► 每个字段的“修正收益”分数 p
   │
   ├── p 低：直接采用小模型结果
   └── p 高：送大模型复核（独立抽取该字段，附定向提示，如“小计+税与总额不符”）
                │
                ▼
          合并结果，输出最终字段
```

### 2.3 创新点

1. **修正收益感知的字段级路由网络**（主创新，深度学习）
   - 输入表示采用**双路径池化**：
     - 片段路径：对小模型预测片段内各词的隐藏层向量做注意力池化；
     - 全局路径：每种字段类型配一个可学习查询向量，对整张票据所有词的隐藏层向量做注意力池化
       （形式为 `softmax(Q·Hᵀ)·H`，借鉴导师工作 VST 的 VS-Align 模块）。
       **小模型漏抽时片段路径没有输入，全局路径仍能提供信息**；
     - 两路用门控融合：`G = σ(W[a; b])`，输出 `G·a + (1−G)·b`（借鉴 PRTR 的 DPSA 模块）。
   - 其他特征：置信度、熵、片段内各词的完整标签概率向量（而非仅最大概率）、字段类型嵌入、归一化位置、一致性特征。
   - 网络：上述池化 + 小型多层感知机，输出“送大模型能被改对”的概率。
   - 训练目标：**小模型错且大模型对**的字段为正样本，其余为负样本。
     与“预测小模型是否出错”相比，可以避免把调用浪费在两个模型都做不对的字段上。
   - 推理：给定调用预算（如 20% 的字段）或阈值，按分数从高到低选字段。
2. **跨字段一致性约束**（票据场景特色）
   - 规则：小计 + 税 + 服务费 − 折扣 ≈ 总额；菜品金额之和 ≈ 小计；现金 − 总额 ≈ 找零；日期格式合法；金额为合法数字等。
   - 用途一：作为路由网络的输入特征。
   - 用途二：复核时生成**定向提示**，告诉大模型哪里不一致。
   - 适用范围：CORD 字段丰富，可做算术校验；SROIE 只有总额，只能做格式校验。论文中如实说明。
3. **两个层面的难样本构造**
   - **特征层面：模拟小模型错误**（借鉴导师工作 PRTR 的在线概率增强 OPA）。
     在 5 折交叉验证预测中，把小模型预测正确的字段人为改错：
     去掉或多加片段首尾的词（模拟边界错误）、换成同类型的其他候选片段（模拟误抽）、置空（模拟漏抽）、
     把词级概率向量替换或混合成其他样本的。利用缓存的词级隐藏层向量和 logits 重新构造特征，不需重跑小模型。
   - **图像层面：拍照场景增强**（模糊、阴影、褶皱、透视变形）让小模型出更多真实错误；同时作为鲁棒性测试集。
   - 两者都只用于扩充路由网络的训练数据，验证集和测试集只用真实错误。

### 2.4 与已有工作的区别（相关工作一章的写法要点）

- 通用级联与路由（FrugalGPT、RouteLLM、Hybrid-LLM）：面向文本问答，按查询或整体输出决策；本文面向票据，按**字段**决策。
- 文档抽取的推理前路由（arXiv 2608.06607）：推理前、以整篇文档为单位估计难度；本文在小模型推理后、按字段、利用**小模型内部表示**决策。
- 修正收益路由（Signed Rescue Routing，arXiv 2609.07786）：提出应预测升级的收益而非错误本身；本文借鉴这一训练目标，并结合文档版面特征与票据一致性约束。
- 票据算术校验（神经符号抽取 arXiv 2512.09666 及业界做法）：通常作为最终检查；本文把它作为**路由信号**和**复核提示**。
- 多阶段纠错式文字识别（导师工作 PRTR，BMVC 2022；ABINet 等）：用纠错模块逐级修正初始预测，
  并指出纠错模块缺少错误样本、语言模型会把正确结果改错。本文借鉴其错误模拟思路和按错误类型分析纠错能力的方法；
  区别在于本文不对所有预测做修正，而是**选择性地**把少量字段交给大模型。
- 视觉—语义对齐（导师工作 VST，BMVC 2022）：用可学习查询从视觉特征中汇聚语义特征；本文用同样的形式做字段级全局池化。

### 2.5 可选扩展方向（时间充裕时加入主线）

几个方向都建立在主线之上，不影响主线的实验设计；做了可以作为额外的创新点或补充实验，没做也不影响论文的完整性。

**扩展一：用大模型的修正结果反哺小模型（知识蒸馏）**

- 思路：把大模型复核改对的字段作为新的标注，回头继续训练 LayoutLMv3；也可以用大模型给无标注或增强后的票据打伪标签。
  小模型越来越强，需要交给大模型的字段就越来越少，形成“协同—蒸馏”的闭环。
- 需要的东西：主线中已经缓存的大模型复核结果；可选的无标注票据图像。
- 实验：比较蒸馏前后小模型单独使用的 F1，以及同一目标 F1 下所需的大模型调用比例是否下降；可以做多轮迭代，画“轮次—调用比例”曲线。
- 注意：伪标签会带入大模型的错误，需要只采用大模型高置信、且通过一致性校验的结果；测试集绝不能参与伪标签。

**扩展二：区域聚焦复核（提速）**

- 思路：复核时不把整张票据交给大模型，而是根据待复核字段的 OCR 框截取附近区域，只把局部图像交给大模型。
  图像更小、问题更简单，单次复核耗时更短。
- 需要设计的部分：截取范围的确定方法（例如以字段框为中心按比例外扩，同行或同列的相关字段一并纳入，
  一致性约束涉及的字段如小计、税、总额一起截取）。漏抽字段没有框，用全局池化路径注意力最高的词的位置代替。
- 实验：比较整图复核与区域复核的单次耗时、显存占用和复核准确率；在核心曲线图上，区域复核应让本文曲线进一步左移。
- 注意：截取过小可能丢失上下文（如字段标题“TOTAL”），需要在验证集上选择外扩比例。

**扩展三：用 OCR 结果约束大模型的修正（降低改错率）**

- 思路：借鉴 PRTR 中视觉—语言重新对齐、防止语言模型“想当然”的思想。大模型给出的修正值若在 OCR 词中找不到
  （编辑距离超过阈值），则不采纳，回退到小模型结果。
- 注意：大模型可能靠看图修正 OCR 错误，这条规则会把这部分收益一起去掉。作为可选开关，是否开启及阈值都在验证集上决定，
  并报告开启前后的改对率和改错率。

## 3. 关键实验设计

### 3.1 路由网络训练数据怎么来（必须遵守）

- **小模型用 5 折交叉验证产生预测**：训练集分 5 份，轮流用 4 份训练、在剩下 1 份上预测，得到“小模型没见过的数据上的预测”。
  不能用小模型在自己训练数据上的预测，否则几乎没有错误，路由网络学不到东西。
- **大模型同样不能在见过的数据上生成标签**：LoRA 若用全部训练集微调，再在训练集上复核，“大模型对”的比例会被高估。
  因此训练集上的大模型结果用 **2 折 LoRA** 产生（用一半训练集微调，在另一半上推理）；验证集和测试集用全部训练集微调的 LoRA。
  时间不够时，退回到用零样本大模型生成标签和做复核，并在论文中说明。
- **大模型复核采用独立抽取**：复核提示中不包含小模型的预测值，只给字段名和（可选的）定向提示，让大模型重新抽取该字段。
  这样大模型是否正确与小模型的预测无关，缓存的结果可以直接给模拟错误样本当标签，无需重跑大模型。
  （定向提示依赖小模型预测；模拟错误样本统一使用不带定向提示的复核结果作标签，论文中说明这一近似。）
- 正样本 = 小模型错 ∧ 大模型对。正样本稀少时，用特征层面的模拟错误和图像层面的增强扩充，并在损失函数中做类别加权或用焦点损失。
- **模拟错误样本只用于训练**，验证集和测试集只使用真实的交叉验证错误，避免路由网络学到“人造错误的痕迹”却在评估中看不出来。
- 路由网络的超参数、阈值、预算只在验证集上选；测试集只在最后报告时跑一次。

### 3.2 对照组

| 类别 | 方案 | 作用 |
|---|---|---|
| 单模型 | 只用 LayoutLMv3 | 速度上限、准确率下限 |
| 单模型 | 只用 Qwen2.5-VL（零样本 / LoRA） | 准确率上限、速度下限 |
| 单模型（可选） | Donut（不依赖 OCR） | 另一条技术路线的参照 |
| 协同 | 随机路由（调用比例与本文相同） | 证明“挑哪些字段”有意义 |
| 协同 | 置信度阈值路由（未校准 / 温度缩放校准） | 证明路由网络优于简单阈值 |
| 协同 | 整张票据复核（任一字段低置信度则整张送大模型） | 证明字段级比票据级更省 |
| 协同 | 预测“小模型是否出错”的路由网络 | 证明“修正收益”目标的作用 |
| 参考线 | Oracle（恰好只送“小模型错且大模型对”的字段） | 理论上限，只用于画图 |
| 本文 | 修正收益路由网络 + 一致性约束 + 定向提示 | — |

### 3.3 消融实验

- 去掉隐藏层向量
- 只用片段池化（去掉全局字段查询路径）；两路直接拼接（去掉门控融合）
- 只用置信度/熵（去掉完整概率向量）
- 去掉一致性特征 / 去掉定向提示
- 训练目标换成“是否出错”
- 不用模拟错误样本 / 不用增强难样本 / 两者都不用
- 大模型不做 LoRA

### 3.4 指标

| 维度 | 指标 |
|---|---|
| 准确度 | 字段级 P / R / F1（逐字段与总体），整张票据全对比例 |
| 速度 | 单张平均耗时、P95 耗时、吞吐量（张/秒） |
| 资源 | 显存峰值、参数量 |
| 路由 | 大模型调用比例、复核后被改对的比例、被改错的比例、大模型输出解析失败率 |

**核心图**：横轴平均耗时（或调用比例），纵轴 F1。两个单模型各一个点，各种路由方法在不同预算下各连成一条曲线。
本文曲线应整体位于其他曲线的左上方。

### 3.5 公平性规则

- 所有方法用同一份训练集、同一个测试集、同一份 OCR 输入、同一套评估代码（`src/eval/metrics.py`）。
- 计时在同一张显卡上进行：先预热若干张不计入；计时范围一致（包含读图与预处理）；批大小一致；计时实验中大模型真实调用，不读缓存。
- 对照组和本文方法同样只在验证集上调参。
- 引用论文中的公开结果只用于说明复现的基线水平正常，不与本文结果直接比较耗时；准确率比较需注明口径差异
  （例如 SROIE 官方排行榜包含 OCR 识别，本文使用数据集自带的 OCR 结果）。

### 3.6 按错误类型分析（借鉴 PRTR 表 1）

把小模型在测试集上的错误字段分为以下几类（判定细节见 `docs/algorithm.md` 第 8.2 节）：

| 错误类型 | 判定方式 | 例子 |
|---|---|---|
| 边界错误 | 预测片段与真实片段有重叠但词不完全相同 | 多带或少带一个词 |
| 值内字符错误 | 片段位置正确，但 OCR 文本与真实值不一致 | `9.00` 识别成 `9.0O` |
| 漏抽 | 预测为空，真实值非空 | — |
| 多抽 | 预测非空，真实值为空 | — |
| 误抽 | 预测片段与真实片段无重叠 | 把小计当成总额 |

对每类报告：占小模型错误的比例、被各路由方法选中的比例（同一调用预算下）、被大模型改对的比例。
用来说明路由网络在哪类错误上优于置信度阈值，以及大模型擅长修正哪类错误。
另外统计大模型把正确结果改错的案例，作为讨论部分的素材。

### 风险与应对

1. **期末考试与春节**（2027 年春节约在 2 月 6 日）落在核心实验阶段：第 1～6 周尽量不拖延。
2. **正样本过少**：交叉验证 + 特征层面模拟错误 + 增强难样本 + 类别加权；若仍不足，可把训练目标放宽为“小模型是否出错”，并作为消融对比。
3. **模拟错误与真实错误分布不一致**：模拟样本只用于训练，评估只用真实错误；用消融实验检验模拟样本是否真的有帮助，没帮助就如实报告并去掉。
4. **大模型推理与微调慢**：2 折 LoRA 加上在交叉验证数据上跑大模型耗时较长，提前用后台脚本批量跑，并缓存结果。
5. **时间不够**：可缩减的部分依次为第 2.5 节的扩展方向、Donut 对照组、鲁棒性实验的规模、2 折 LoRA（退回零样本标签）；路由网络与对照组不可缩减。
6. **论文不要最后才写**：每个阶段结束时写好对应章节草稿。
