# 技术方案与时间规划

## 1. 题目与核心主张

**暂定题目**：面向票据关键信息抽取的修正收益感知字段级路由方法

**一句话概括**：小模型（LayoutLMv3）先抽取所有字段；一个自己设计并训练的**路由网络**判断每个字段“交给大模型（Qwen2.5-VL）复核后能不能被改对”，只把值得复核的字段送给大模型。

**论文要证明的主张**：在准确率接近“只用大模型”的前提下，把耗时和大模型调用量降到接近“只用小模型”；
并且在相同调用预算下，路由网络挑出的字段被改对的数量明显多于“按置信度挑”和“随机挑”。

## 2. 方法

### 2.1 通俗理解

| 角色 | 对应模块 | 特点 |
|---|---|---|
| 实习生 | 小模型 LayoutLMv3 | 快、便宜，大部分正确，偶尔出错，自报的把握不太准 |
| 老会计 | 大模型 Qwen2.5-VL-3B（LoRA） | 准但慢，不能每张都看 |
| 审核主管 | **路由网络（本文设计）** | 判断哪个字段交给老会计能被改对 |

### 2.2 整体流程

```
票据图像 + OCR
   │
   ▼
LayoutLMv3 抽取 ──► 每个字段：预测值、词级概率、隐藏层向量
   │
   ▼
特征构造 ──► 隐藏层向量（注意力池化）+ 置信度/熵 + 字段类型/位置 + 一致性校验结果
   │
   ▼
路由网络 ──► 每个字段的“修正收益”分数 p
   │
   ├── p 低：直接采用小模型结果
   └── p 高：送大模型复核（附定向提示，如“小计+税与总额不符”）
                │
                ▼
          合并结果，输出最终字段
```

### 2.3 创新点

1. **修正收益感知的字段级路由网络**（主创新，深度学习）
   - 输入：小模型在该字段词上的隐藏层向量，经注意力池化汇成一个向量；拼接置信度、熵、字段类型嵌入、归一化位置、一致性特征。
   - 网络：注意力池化 + 小型多层感知机，输出“送大模型能被改对”的概率。
   - 训练目标：**小模型错且大模型对**的字段为正样本，其余为负样本。
     与“预测小模型是否出错”相比，可以避免把调用浪费在两个模型都做不对的字段上。
   - 推理：给定调用预算（如 20% 的字段）或阈值，按分数从高到低选字段。
2. **跨字段一致性约束**（票据场景特色）
   - 规则：小计 + 税 + 服务费 − 折扣 ≈ 总额；菜品单价 × 数量 ≈ 金额；日期格式合法；金额为合法数字等。
   - 用途一：作为路由网络的输入特征。
   - 用途二：复核时生成**定向提示**，告诉大模型哪里不一致。
   - 适用范围：CORD 字段丰富，可做算术校验；SROIE 只有总额，只能做格式校验。论文中如实说明。
3. **难样本构造**（与鲁棒性模块结合）
   - 拍照场景增强（模糊、阴影、褶皱、透视变形）让小模型出更多错，为路由网络提供足够的正样本；
     同时作为鲁棒性测试集。

### 2.4 与已有工作的区别（相关工作一章的写法要点）

- 通用级联与路由（FrugalGPT、RouteLLM、Hybrid-LLM）：面向文本问答，按查询或整体输出决策；本文面向票据，按**字段**决策。
- 文档抽取的推理前路由（arXiv 2608.06607）：推理前、以整篇文档为单位估计难度；本文在小模型推理后、按字段、利用**小模型内部表示**决策。
- 修正收益路由（Signed Rescue Routing，arXiv 2609.07786）：提出应预测升级的收益而非错误本身；本文借鉴这一训练目标，并结合文档版面特征与票据一致性约束。
- 票据算术校验（神经符号抽取 arXiv 2512.09666 及业界做法）：通常作为最终检查；本文把它作为**路由信号**和**复核提示**。

### 2.5 可选扩展方向（时间充裕时加入主线）

两个方向都建立在主线之上，不影响主线的实验设计；做了可以作为额外的创新点或补充实验，没做也不影响论文的完整性。

**扩展一：用大模型的修正结果反哺小模型（知识蒸馏）**

- 思路：把大模型复核改对的字段作为新的标注，回头继续训练 LayoutLMv3；也可以用大模型给无标注或增强后的票据打伪标签。
  小模型越来越强，需要交给大模型的字段就越来越少，形成“协同—蒸馏”的闭环。
- 需要的东西：主线中已经缓存的大模型复核结果；可选的无标注票据图像。
- 实验：比较蒸馏前后小模型单独使用的 F1，以及同一目标 F1 下所需的大模型调用比例是否下降；可以做多轮迭代，画“轮次—调用比例”曲线。
- 注意：伪标签会带入大模型的错误，需要只采用大模型高置信、且通过一致性校验的结果；测试集绝不能参与伪标签。

**扩展二：区域聚焦复核（提速）**

- 思路：复核时不把整张票据交给大模型，而是根据待复核字段的 OCR 框截取附近区域，只把局部图像交给大模型。
  图像更小、问题更简单，单次复核耗时更短。
- 需要设计的部分：截取范围的确定方法（例如以字段框为中心按比例外扩，同行或同列的相关字段一并纳入，
  一致性约束涉及的字段如小计、税、总额一起截取）。
- 实验：比较整图复核与区域复核的单次耗时、显存占用和复核准确率；在核心曲线图上，区域复核应让本文曲线进一步左移。
- 注意：截取过小可能丢失上下文（如字段标题“TOTAL”），需要在验证集上选择外扩比例。

## 3. 关键实验设计

### 3.1 路由网络训练数据怎么来（必须遵守）

- **小模型用 5 折交叉验证产生预测**：训练集分 5 份，轮流用 4 份训练、在剩下 1 份上预测，得到“小模型没见过的数据上的预测”。
  不能用小模型在自己训练数据上的预测，否则几乎没有错误，路由网络学不到东西。
- **大模型在同样的数据上也跑一遍**，得到每个字段“大模型是否正确”。
- 正样本 = 小模型错 ∧ 大模型对。正样本稀少时，用增强图像扩充，并在损失函数中做类别加权或用焦点损失。
- 路由网络的超参数、阈值、预算只在验证集上选；测试集只在最后报告时跑一次。

### 3.2 对照组

| 类别 | 方案 | 作用 |
|---|---|---|
| 单模型 | 只用 LayoutLMv3 | 速度上限、准确率下限 |
| 单模型 | 只用 Qwen2.5-VL（零样本 / LoRA） | 准确率上限、速度下限 |
| 单模型（可选） | Donut（不依赖 OCR） | 另一条技术路线的参照 |
| 协同 | 随机路由（调用比例与本文相同） | 证明“挑哪些字段”有意义 |
| 协同 | 置信度阈值路由（未校准 / 温度缩放校准） | 证明路由网络优于简单阈值 |
| 协同 | 整张票据复核（任一字段低置信度则整张送大模型） | 证明字段级比票据级更省 |
| 协同 | 预测“小模型是否出错”的路由网络 | 证明“修正收益”目标的作用 |
| 本文 | 修正收益路由网络 + 一致性约束 + 定向提示 | — |

### 3.3 消融实验

去掉隐藏层向量 / 去掉一致性特征 / 去掉定向提示 / 训练目标换成“是否出错” / 不用增强难样本 / 大模型不做 LoRA。

### 3.4 指标

| 维度 | 指标 |
|---|---|
| 准确度 | 字段级 P / R / F1（逐字段与总体），整张票据全对比例 |
| 速度 | 单张平均耗时、P95 耗时、吞吐量（张/秒） |
| 资源 | 显存峰值、参数量 |
| 路由 | 大模型调用比例、复核后被改对的比例、被改错的比例 |

**核心图**：横轴平均耗时（或调用比例），纵轴 F1。两个单模型各一个点，各种路由方法在不同预算下各连成一条曲线。
本文曲线应整体位于其他曲线的左上方。

### 3.5 公平性规则

- 所有方法用同一份训练集、同一个测试集、同一份 OCR 输入、同一套评估代码（`src/eval/metrics.py`）。
- 计时在同一张显卡上进行：先预热若干张不计入；计时范围一致（包含读图与预处理）；批大小一致。
- 对照组和本文方法同样只在验证集上调参。
- 引用论文中的公开结果只用于说明复现的基线水平正常，不与本文结果直接比较耗时；准确率比较需注明口径差异
  （例如 SROIE 官方排行榜包含 OCR 识别，本文使用数据集自带的 OCR 结果）。

### 风险与应对

1. **期末考试与春节**（2027 年春节约在 2 月 6 日）落在核心实验阶段：第 1～6 周尽量不拖延。
2. **正样本过少**：交叉验证 + 增强难样本 + 类别加权；若仍不足，可把训练目标放宽为“小模型是否出错”，并作为消融对比。
3. **大模型推理慢**：在交叉验证数据上跑大模型耗时较长，提前用后台脚本批量跑，并缓存结果。
4. **时间不够**：可缩减的部分依次为第 2.5 节的扩展方向、Donut 对照组、鲁棒性实验的规模；路由网络与对照组不可缩减。
5. **论文不要最后才写**：每个阶段结束时写好对应章节草稿。
